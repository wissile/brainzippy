# Animation & Audio

## Timing rules
| Event | Visual | Audio | Duration |
|---|---|---|---|
| Any tap | press-down 120 ms | `tap` (or count note) | <100 ms to respond |
| Count an object | badge pops (260 ms bounce) | `count` pitched up a pentatonic step per count + number word | — |
| Add to basket | plop-in 260 ms | `drop` + count note + number word | — |
| Correct | confetti 1.1 s, choice turns gold, star pops | `correct` arpeggio, then `star` at 350 ms, praise line | ≥1.7 s then advance |
| Wrong (1st) | choice nudges ±8 px, greys out; Bobbo retry pose | `retry` (soft descending 2 notes) + hint line | ~1–3 s |
| Count-along hint | objects highlight in reading order, 700 ms each | `hint` twinkle, count notes + number words | n × 0.7 s |
| Model answer | correct choice pulses (1 s loop), others disabled | "It's N! Tap N." | until tapped |
| Round complete | Bobbo celebrates, big confetti | `complete` jingle + line | ~2.6 s |
| Achievement | sticker spins in 0.9 s, rays rotate 14 s | `achievement` chord + lines | — |
| Idle 9 s | hand pointer at next target | instruction replays | repeats every 9 s idle |
Only `transform`/`opacity` animate. Reduced motion collapses durations to 1 ms and swaps pulses for thick outlines.

## Sound effects (original, synthesized)
Generated by `scripts/gen_sfx.py` (numpy additive synthesis + generated reverb → mp3 96 kbps mono, peak −3 to −12 dBFS). 11 files, 168 KB: `tap, count, pickup, drop, correct, retry, hint, whoosh, complete, achievement, star`. Fully owned; regenerate with `npm run gen:sfx`.

Sound categories required by the brief → asset: welcome (`whoosh` + greeting line) · instructions (voice) · interaction (`tap`, `count`, `pickup`, `drop`) · correct (`correct`, `star`) · incorrect (`retry`) · hint (`hint`) · level completion (`complete`) · achievement (`achievement`).

## Voice
- **Current (milestone 1): browser speech synthesis** with a preferred-voice list (natural English voices first), rate 0.92, pitch 1.2. Quality and availability **vary by device** — this is a known, explicitly flagged limitation, not the production voice.
- **Production plan:** cast an original voice actor for Bobbo (warm, eager, ~6–9-year-old energy, not imitating any performer or existing character). Record every line in `voiceLines.ts` (≈45 lines + numbers 1–12), 48 kHz WAV masters → mono Opus/MP3, loudness −16 LUFS, add `file` to each catalogue entry. The engine already prefers files and falls back to synthesis.
- Captions: every line is captioned in a speech bubble (lingers 1.8 s) and an `aria-live` region.

## Behaviour
- Audio context unlocks on the first tap (browser policy). Mute toggle persists locally; muted mode keeps captions and shortens waits.
- All audio is fail-soft: missing files, blocked autoplay, or no voices never block play (capped waits). Verified by e2e "audio files failing".
